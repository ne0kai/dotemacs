My personal Emacs configuration.

# Features

- Evil keybindings, but lighter.
- Minimal, elegant interface.
- Modular.

# macOS Prerequisites

Full support for macOS.

- emacs-plus 29+.
- iTerm2 terminal emulator.
- nerd fonts (e.g. `font-roboto-mono-nerd-font`)
- iA writer fonts (available from <https://github.com/iaolo/iA-Fonts>)
- input methods.
  Refer to [emacs smart input source](https://github.com/laishulu/emacs-smart-input-source) and [emacs-rime](https://github.com/DogLooksGood/emacs-rime) for instructions on installation.
  Note that you need to update the value of `rime-emacs-module-header-root` after each upgrade of Emacs.
- `rg`, `opencc`, `aspell` or similar
- `Marked 2` app for previewing markdown files.

# Linux Prerequisites

Partial support for Arch linux.

- `SFMono Nerd Font`, `Libertinus Sans`, `Apple Color Emoji` and `iA Writer Duospace` are available either in arch repository or as AUR.
- input methods: see above.
- `rg`, `opencc`, `goldendict`.
